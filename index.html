About The Project

Step into the classic arena of decision-making! Whether you're settling a friendly debate or testing your luck against the computer, this Rock-Paper-Scissors game brings a modern twist to a timeless classic. Play through 5 strategic rounds, track live scores, and see if you have what it takes to claim ultimate victory!

Designed with a sleek user interface and smooth user experience, this application showcases clean event-driven DOM manipulation, seamless state management without page refreshes, and responsive web design principles.

Tech Stack & Features

  • HTML5: Semantic structure for clear hierarchy and web accessibility.
  • CSS3: Custom layout control using Flexbox, smooth transitions, and responsive design.
  • JavaScript (ES6+): Pure Vanilla JS focusing on dynamic DOM manipulation and state management.
